# Syntax Wear App
Landing page de moda e sneakers em desenvolvimento, criada com **React, TypeScript, Vite e Tailwind CSS**, com foco em componentização, responsividade e experiência do usuário.

## Status do Projeto
**Em desenvolvimento**
O projeto está sendo construído e receberá novas funcionalidades, melhorias visuais e ajustes de responsividade conforme sua evolução.

## Sobre o Projeto
O **Syntax Wear App** é uma aplicação Front-End inspirada no universo de moda e sneakers.
A proposta é criar uma interface moderna para apresentação de produtos, utilizando uma estrutura baseada em componentes reutilizáveis e uma organização preparada para receber novas funcionalidades.
O projeto também serve como prática para consolidar conhecimentos em **React, TypeScript e Tailwind CSS**.

## Funcionalidades
Atualmente, o projeto conta com uma estrutura inicial de interface composta por:
* Header
* Hero section
* Categorias
* Galeria de produtos
* Botões reutilizáveis
* Imagens e elementos visuais relacionados a sneakers
* Layout desenvolvido com componentes React
Novos recursos serão adicionados durante a evolução do projeto.

## Como Rodar o Projeto
### Pré-requisitos

* Node.js
* npm

### 1. Clone o repositório
```bash
git clone https://github.com/devseravali/syntax-wear-app.git
```

### 2. Acesse a pasta
```bash
cd syntax-wear-app
```

### 3. Instale as dependências
```bash
npm install
```

### 4. Execute o projeto
```bash
npm run dev
```

O Vite disponibilizará a aplicação no endereço informado no terminal.

## Scripts Disponíveis
### Desenvolvimento
```bash
npm run dev
```

### Build
```bash
npm run build
```

### Lint
```bash
npm run lint
```

### Preview
```bash
npm run preview
```

Os scripts estão definidos no `package.json` e utilizam Vite para desenvolvimento e build, TypeScript para verificação de tipos e ESLint para análise do código.
